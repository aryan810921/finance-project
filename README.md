## 🚀 Run Locally

bash
git clone <your-repository-url>
cd finance-project


### Backend

bash
cd backend
npm install
npm start


### Frontend

bash
cd frontend
npm install
npm run dev

## 🔌 Core APIs

|  Method | Endpoint                 | Purpose             |
| :-----: | ------------------------ | ------------------- |
|  POST | /api/auth/register     | 👤 Register         |
|  POST | /api/auth/login        | 🔑 Login            |
|  POST | /api/auth/logout       | 🚪 Logout           |
|  POST | /api/finance           | 💰 Add finance data |
| PATCH | /api/finance           | ✏️ Update finance   |
|  POST | /api/finance/goals     | 🎯 Create goal      |
|  GET  | /api/finance/dashboard | 📊 Dashboard        |
